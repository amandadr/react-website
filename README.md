# Amanda Roy — Developer Portfolio

This repository contains the source code for [amandadroy.com](https://amandadroy.com), my personal development portfolio.

The site documents my work across frontend and full-stack development, technical projects, and earlier stages of my career in software development. It serves as a more code-focused counterpart to my consulting work at [Manny Roy Consulting](https://www.mannyroy.com).

## About the Site

I built this portfolio to bring together projects, technologies, and experience from across my development career in one place.

The site includes:

- Selected development projects
- Career and experience timeline
- Technologies and tools I've worked with
- Responsive layouts and interactive components
- Light and dark display modes

While my work has since expanded into platform architecture, automation, technical SEO, applied AI, and broader digital systems, I continue to maintain this site as a record of my development background.

## Tech Stack

The site is built with:

- React 18
- Sass
- Bootstrap / React Bootstrap
- React Vertical Timeline
- React Awesome Slider
- React Switch
- Iconify
- GitHub Pages

## Running Locally

Clone the repository and install dependencies:

```bash
git clone https://github.com/amandadr/react-website.git
cd react-website
npm install
```

Start the development server:

```bash
npm start
```

Create a production build with:

```bash
npm run build
```

## Deployment
